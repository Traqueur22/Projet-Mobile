# Hello World — Flutter

Un projet Flutter minimal qui affiche **Hello World** au centre de l'écran.

## Prérequis

- Le [SDK Flutter](https://docs.flutter.dev/get-started/install)
- Un émulateur, un simulateur ou un appareil connecté

## Lancer l'application

Depuis ce dossier :

```bash
flutter pub get
flutter run
```

## Vérifier le projet

```bash
flutter analyze
flutter test
```

## Structure

