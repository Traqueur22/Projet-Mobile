# Projet-Mobile — Cours de programmation mobile

Projet de départ Flutter pour les exercices du cours.

## Prérequis

- Flutter SDK installé et disponible dans le `PATH`
- Un émulateur Android/iOS ou un appareil connecté

## Démarrer

```sh
flutter pub get
flutter run
```

## Structure

- `lib/main.dart` : point d’entrée et écran d’accueil de l’application
- `pubspec.yaml` : métadonnées et dépendances Flutter

Ajoutez vos exercices dans `lib/` et vos ressources dans `assets/` (pensez à les déclarer dans `pubspec.yaml`).
